# 근로기준법 판별기

상시 근로자 수와 사례를 입력하면 관련 조문, 5인 미만 사업장 특례 적용 여부, 대법원 판례, 고용노동부 해석을 찾아 보여 주는 웹 페이지입니다.

사이트: https://zenning25.github.io/labor-check/

참고용 정보이며 법률 자문이 아닙니다. 실제 분쟁은 노동청 또는 공인노무사와 상담하시기 바랍니다.

## 내려받아 쓰기

인터넷 없이 쓰려면 `download/근로기준법_판별기_로컬.zip`을 내려받아 압축을 풀고, 안에 있는 `근로기준법_판별기_로컬.html`을 더블클릭하세요. 브라우저에서 열립니다. 데이터가 파일 안에 들어 있어서 서버가 필요 없습니다(풀면 12.8MB). 사이트보다 판례와 해석 요지를 짧게 담았고, 해석은 근로기준법 관련 쟁점만 넣었습니다.

## 무엇을 하나요

- 근로기준법, 시행령, 시행규칙의 조문을 보여 주고, 시행령 별표 1(4명 이하 사업장에 적용하는 규정)과 대조해 5인 미만 사업장 적용 여부를 표시합니다.
- 최저임금법, 근로자퇴직급여 보장법, 산업재해보상보험법, 산업안전보건법, 고용보험법, 남녀고용평등법, 기간제법, 파견법, 노조법, 근로자참여법, 임금채권보장법의 적용 범위 조문을 원문으로 보여 줍니다.
- 대법원 판례 2,612건과 고용노동부 법령해석 4,128건에서 사례와 관련된 것을 찾습니다.
- 자동 판정은 해고예고(근로기준법 제26조)와 별표 1 대조까지입니다. 사실관계를 반영한 최종 판단은 화면의 Claude 요청문을 사용합니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html`, `data/` | 공개 사이트 (GitHub Pages). `data/*.json`은 화면이 불러오는 요약 데이터입니다. |
| `scripts/collect.ps1` | 국가법령정보센터 Open API에서 근로기준법 3종, 판례, 고용노동부 해석을 받습니다. |
| `scripts/collect_laws.ps1` | 근로기준법 외 노동 관련 법령 11개와 시행령을 받습니다. |
| `scripts/build_local.ps1` | 받은 데이터로 `docs/`(사이트용)와 단일 HTML 파일을 만듭니다. |
| `scripts/template.html` | 화면과 검색 로직입니다. |
| `scripts/law_scope.json` | 법령별 적용 범위 메모입니다. 각 메모는 조문 원문을 읽고 확인한 내용만 담았습니다. |
| `raw-data/` | 수집한 원본 JSON 전체를 압축한 파일입니다. |
| `download/` | 더블클릭으로 쓰는 단일 HTML 파일(압축)입니다. |

## 다시 만드는 방법 (Windows PowerShell)

1. open.law.go.kr에서 Open API를 신청하고 인증키(OC)를 받습니다. 현행법령, 판례, 고용노동부 법령해석의 목록과 본문 JSON이 필요합니다.
2. 인증키를 환경변수에 넣습니다. 키는 저장소에 올리지 마세요.
   `$env:LAW_OC = '발급받은값'`
3. 수집합니다.
   `.\scripts\collect.ps1`
   `.\scripts\collect_laws.ps1`
4. 빌드합니다. `docs/` 폴더에 사이트 파일이 만들어집니다.
   `.\scripts\build_local.ps1`
5. `docs/index.html`과 `docs/data/*.json`을 이 저장소 루트의 `index.html`, `data/`에 올립니다.

원본 데이터를 다시 받지 않고 빌드만 하려면 `raw-data/`의 zip을 풀어 `data/` 폴더에 넣은 뒤 4번부터 하면 됩니다.

## 한계

- 데이터는 수집한 시점 기준입니다. 법령이 개정되거나 새 판례가 나와도 자동으로 갱신되지 않습니다. 화면 하단의 데이터 기준일을 확인하세요.
- 노동조합 및 노동관계조정법은 규모에 따라 적용을 제한하는 조문을 확인하지 못해 "원문 확인 필요"로 표시합니다.
- 산업안전보건법의 규정별 5인 미만 적용 여부는 시행령 별표 1 원문을 보여 주고, 조문별 자동 대조는 하지 않습니다.
- 판례와 해석은 키워드 일치도로 고른 후보입니다. 쟁점에 맞는지는 요지를 읽고 판단해야 합니다.

## 출처

법령, 판례, 법령해석은 국가법령정보센터(law.go.kr) Open API에서 받은 공개 자료입니다.
